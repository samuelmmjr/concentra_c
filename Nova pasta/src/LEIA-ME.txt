CASCO — REVISÃO DE CONVERSÃO EM ASTRO

No projeto existente:
1. Substitua src/pages/index.astro pelo arquivo deste pacote.
2. Substitua src/styles/global.css pelo arquivo deste pacote.
3. Copie public/images para public/images do projeto.
4. Execute npm run dev. Para produção, execute npm run build.

Este pacote contém os arquivos de substituição, não um novo projeto npm.
Não renomeie index.astro para HTML. O CSS é importado no início do componente.
Os kits 1, 2, 3 e 6 têm os checkouts individuais enviados.
Os CTAs principais destacam o kit de 2 frascos.
